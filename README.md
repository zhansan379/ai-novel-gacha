# AI 命运抽卡 · 互动小说生成系统

> 一句话：你给一句灵感，它帮你生成一整本可以"抽卡玩"的互动小说。每到一个剧情岔路口，给你几张"命运卡"，你抽一张（或自己输入一句话），它就顺着往下写一段，一直写到故事完结。

**当前状态**：完整流程已跑通——开书（后台自动建世界观/人物/伏笔/人物关系）→ 每步抽卡或自由发挥 → 正文边写边显示 → 自动查前后矛盾、去"AI 腔" → 自动分章、判断何时完结。还接了"联网查证真实信息"，写真实题材不容易出错。数据存在本地，重启不丢。要先在设置里填你自己的模型（接入后就能用）。

## 核心玩法

一句话流程：

```
写着写着 → 到岔路口 → 生成 3~5 张命运卡
   → ① 盲抽（随机揭晓） | ② 明选（把卡摊开选） | ③ 自己输入一句引导
   → 顺着所选往下写一段正文 → 自动查前后矛盾 → 到下一个岔路口 → 循环
   → 判断该收章 / 该完结 → 自动分章收尾
```

卡分稀有度：普通 / 稀有 / 史诗 / 传说，越稀有剧情张力越高。下一批卡等正文写完才生成，不会让你一直等转圈。

## 功能一览

- 一句话灵感自动开书，建出世界观、历史线、人物、伏笔和人物关系
- 抽卡玩法 + 自由输入，两种方式都能引导剧情
- 正文边写边显示，不用等全部写完
- 自动查前后矛盾、识别并去掉"AI 腔"
- 自动分章，并判断整本书什么时候该收尾
- 联网查证真实信息，写真实人物/事件不容易写错、写反
- 人物关系图谱可视化
- 书签、收藏、导入导出（md / txt / json）、撤销上一步
- 阅读翻页模式、主题与字体字号设置
- 多用户，每人可带自己的模型
- 数据本地持久化，重启不丢

## 踩过的坑（节选）

- **AI 写的东西一个味、爱编设定** → 开书先判断这本书是什么题材，把"该避点什么、按什么节奏写"的约束塞给 AI；简介单独用更高的创作温度，求新颖。
- **真实题材容易漏查证、写反关系** → 开书先判"这本书需要哪些资料"，需要就联网查好喂给正文；遇到真实人物，把"帮助→报恩→共事"这类关系方向固化为硬约束，保证不写反。
- **长书越写越乱、也停不下来** → 生成时只塞"最近几拍剧情 + 当下相关的设定"，避免上下文无限堆积；每段写完让 AI 判断该不该收章/完结，配上限兜底，防止一直续写。
- **AI 输出格式不稳定、容易崩** → 写了一套稳妥的解析逻辑，把模型爱包的代码块、前后夹带的话都处理掉，并把"下一批卡"改成需要时再生成，按节点加锁防止重复提交弹错。

## 本地怎么跑

### 后端

```bash
cd backend
uv sync
uv run pytest         # 跑一遍测试
uv run uvicorn app.main:app --reload --port 8000
# 检查是否正常：GET http://localhost:8000/v1/health
```

### 接入真实模型（不用改代码）

打开前端页面 → 右上角「⚙ 模型」→ 填服务商 / 模型名 / 接口地址 / 密钥 → 保存。
也可以把配置写进 `backend/.env`（字段见 `.env.example`）。

> 没填模型就去生成，系统会给一个明确提示，不会再默默糊弄过去。

### 前端

```bash
cd frontend
npm install
npm run dev         # 打开 http://localhost:5173（接口会自动转发到 :8000）
```
